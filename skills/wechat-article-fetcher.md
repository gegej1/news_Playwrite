# 微信公众号文章抓取器

通过 Playwright MCP 自动抓取微信公众号文章内容，绕过验证码限制。

## 何时使用

- 用户提供微信公众号文章链接（mp.weixin.qq.com）
- 需要提取公众号文章的完整文本内容
- 需要批量获取公众号文章信息

## 工作原理

使用 Playwright MCP 工具直接访问微信公众号文章链接：

1. 直接打开文章 URL（通常不会触发验证码）
2. 等待页面加载完成
3. 提取页面快照获取文章内容
4. 解析并返回结构化的文章信息

## 使用方法

当用户提供微信公众号文章链接时：

```
用户：帮我读取这篇文章的内容 https://mp.weixin.qq.com/s/xxxxx
```

你应该：

1. 使用 `mcp__chrome-devtools__new_page` 打开文章链接
2. 使用 `mcp__chrome-devtools__take_snapshot` 获取页面内容
3. 从快照中提取：
   - 文章标题（heading level="1"）
   - 作者信息
   - 公众号名称
   - 发布时间
   - 文章正文内容（所有 StaticText 和 LineBreak）
   - 图片链接（image 元素）

## 注意事项

### 验证码处理

如果遇到验证码页面（标题包含"环境异常"或"验证码"），有两个策略：

1. **重新尝试**：关闭页面，等待几秒后重新打开
2. **告知用户**：说明遇到了验证码，无法自动绕过

### 内容提取

- 文章内容通常很长，应该分段输出
- 优先提取关键信息：标题、作者、核心观点
- 如果用户需要完整内容，再逐步输出详细内容

## 示例代码流程

```javascript
// 1. 打开文章页面
mcp__chrome-devtools__new_page({
  url: "https://mp.weixin.qq.com/s/xxxxx"
})

// 2. 获取页面快照
mcp__chrome-devtools__take_snapshot()

// 3. 解析快照内容并格式化输出
```

## 输出格式

```markdown
## 文章信息
- **标题**：[文章标题]
- **作者**：[作者名]
- **公众号**：[公众号名称]
- **发布时间**：[发布时间]

## 文章内容

[正文内容，按段落组织]
```

## 限制

- 仅支持公开可访问的文章
- 频繁访问可能触发微信的反爬虫机制
- 无法获取文章的阅读量、点赞数等互动数据
